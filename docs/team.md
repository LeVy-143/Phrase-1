# Đăng ký nhóm Phase 1 — cần nhóm điền tên
Đề tài: IELTS Learning Agent (Academic). Use case đầu tiên: UC-03 Speaking Mock Test text.
Nhóm 4 thành viên: giảng viên chấp thuận theo xác nhận của người dùng.

| Mã phân công | Tên/biệt danh | Phụ trách |
|---|---|---|
| TV1 | Chưa cung cấp | UI app.py |
| TV2 | Chưa cung cấp | Agent, tools, RAG, skills |
| TV3 | Chưa cung cấp | SQLite, storage, bank, data |
| TV4 | Chưa cung cấp | Evaluation, CI, tích hợp, README |

Người sở hữu UC-03: đề xuất TV2 theo phần agent, **chưa xác nhận tên chính thức**.
Không bịa tên sinh viên hoặc khẳng định đã đăng ký lên hệ thống của trường.
Nhóm điền tên và owner trước khi nộp; toàn đồ án sau này mỗi SV cần sở hữu ≥1 UC
và tập UC phải phủ K1–K8 (UC-03 một mình chưa phủ đủ).
